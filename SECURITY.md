# Security Policy

## Supported versions

This project is in an early stage. Security reviews apply to the latest version on the main branch.

## Reporting a vulnerability

Please report security or privacy concerns by opening a private security advisory if available, or by contacting the maintainer.

Do not publicly disclose vulnerabilities that could expose users to harm before the maintainer has had reasonable time to respond.

## Security priorities

This project is designed for rehabilitation and education contexts, so privacy and safety are important even when no server is used.

Security review should focus on:

- unnecessary data collection
- local storage behavior
- export files that may include personal data
- third-party dependencies
- script injection risks
- accessibility and misuse risks
- misleading clinical claims

## Current data policy

The initial tools run locally in the browser and do not send data to external servers by default.
