# Contributing

Thank you for your interest in Therabby Clinical Tools.

## Who can contribute?

We welcome contributions from:

- occupational therapists
- rehabilitation professionals
- educators
- researchers
- developers
- designers
- accessibility specialists
- patients, family members, and community supporters

## Types of contributions

You can contribute by:

- reporting bugs
- suggesting new clinical use cases
- improving documentation
- improving accessibility
- reviewing privacy or safety risks
- adding small browser-based tools
- translating documentation
- writing tests

## Clinical safety principles

Please avoid claims that a tool can diagnose, treat, cure, or predict outcomes unless supported by appropriate evidence and governance.

Prefer wording such as:

- education support
- activity design support
- practice support
- observation aid
- participation support

Avoid wording such as:

- diagnostic tool
- validated medical assessment
- treatment effect guaranteed
- AI clinical decision-making

## Pull request checklist

Before submitting a pull request:

- [ ] The tool does not collect unnecessary personal data
- [ ] Clinical limitations are clearly described
- [ ] Keyboard operation is considered
- [ ] Color alone is not used as the only cue
- [ ] The README or documentation is updated
- [ ] The change is small enough to review

## Development approach

This repository favors small, auditable, browser-based tools over complex systems.

When adding a tool, describe:

1. Purpose
2. Target users
3. Use setting
4. Inputs
5. Outputs
6. Risks
7. Clinical limitations
8. Possible occupational therapy use cases
