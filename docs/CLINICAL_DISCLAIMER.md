# Clinical Disclaimer

Therabby Clinical Tools are provided for education, activity analysis, rehabilitation task design, accessibility exploration, and clinical workflow support.

They are not medical devices and are not intended to diagnose, treat, cure, prevent, or predict any disease or disability.

Use of these tools must be guided by qualified professionals when used in clinical or educational settings.

## Important limitations

- These tools do not replace standardized assessments.
- These tools do not replace clinical reasoning.
- These tools should not be used as the sole basis for decisions about diagnosis, discharge, driving, work return, medication, safety restrictions, or care level.
- If data are used for research, appropriate consent, anonymization, and ethical review may be required.

## Recommended use

Use these tools as:

- conversation aids
- activity analysis supports
- education materials
- task design prototypes
- observation prompts
- practice environments

Always adapt them to the user's goals, context, abilities, risks, and environment.
