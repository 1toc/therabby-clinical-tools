# Privacy

The initial version of Therabby Clinical Tools is local-first.

## Default behavior

- No account is required.
- No server is required.
- No data is sent externally by default.
- Tools run in the browser.

## When exporting or recording data

Users should avoid entering personally identifiable information unless necessary and properly governed.

Clinical and research use may require:

- informed consent
- anonymization or pseudonymization
- institutional rules
- ethics review
- secure storage
- clear deletion procedures

## Future development principles

- Collect the minimum data necessary
- Prefer local-only storage
- Make data flow visible to users
- Avoid hidden analytics by default
- Keep clinical notes and personal health information out of demos
