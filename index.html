Open-source rehabilitation tools

Therabby Clinical Tools

Browser-based tools for occupational therapy, rehabilitation education, activity analysis, accessibility training, and participation support.

These tools are educational and supportive. They do not replace clinical judgment, diagnosis, or standardized assessment.

Activity Analysis Builder

Create a simple occupational therapy activity analysis note with client factors, performance skills, environment, meaning, and adaptation ideas.

Open tool

Visual Scanning Trainer

A simple visual search task for observation and practice. Designed for education and task design, not diagnosis.

Open tool

One-Hand Interaction Trainer

Practice basic pointer interactions using one hand: pointing, clicking, holding, and timing.

Open tool

Project principles

  • Local-first and privacy-aware
  • Small, inspectable, modifiable tools
  • Designed for clinical education and responsible adaptation
  • Accessible and keyboard-friendly where possible
